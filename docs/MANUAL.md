# 사용 매뉴얼

컴퓨터 사용에 익숙하지 않은 분도 따라 할 수 있도록 순서대로 정리했습니다.

## 1. 준비물
1. **Python 3.10 이상**: https://www.python.org/downloads/ 에서 설치합니다.
   Windows에서는 설치 첫 화면의 "Add python.exe to PATH"를 꼭 체크하세요.
2. **Claude API 키**: https://console.anthropic.com 에 가입한 뒤 "API Keys"에서 발급합니다. `sk-ant-`로 시작합니다.
3. 이 프로그램 폴더 (GitHub에서 "Code → Download ZIP"으로 받아 압축을 풉니다).

## 2. 실행
- Windows: 폴더 안의 `run.bat`을 더블클릭합니다.
- macOS: 터미널을 열고 폴더로 이동한 뒤 `./run.sh`를 입력합니다.

처음에는 필요한 프로그램을 설치하느라 몇 분 걸립니다. 설치가 끝나면 브라우저에 "탐라 데이터 비서" 화면이 열립니다.
열리지 않으면 브라우저 주소창에 `http://localhost:8501`을 입력하세요.

## 3. 화면 사용법
1. 왼쪽 **설정 → Claude API 키**에 키를 붙여 넣습니다. (`.env` 파일에 넣어 두면 매번 입력하지 않아도 됩니다.)
2. **데이터 추가**: 제주데이터허브·제주빅데이터센터에서 받은 CSV나 엑셀 파일을 끌어다 놓습니다.
   한글 인코딩(CP949, EUC-KR)도 자동으로 인식합니다.
3. **사용 중인 데이터**에서 파일을 눌러 내용을 미리 볼 수 있습니다.
4. 아래 입력창에 질문을 씁니다. 처음에는 화면의 예시 질문 버튼을 눌러 보세요.
5. 분석 중에는 "데이터 구조 살펴보기", "데이터 집계" 같은 진행 단계가 표시됩니다.
6. 답변 아래의 표·차트를 확인하고, **보고서 내려받기 (HTML)** 로 저장해 공유할 수 있습니다.
7. 주제를 바꾸려면 **새 대화 시작**을 누릅니다.

## 4. 질문 잘하는 법
| 이렇게 물어보면 | 더 좋은 질문 |
|---|---|
| 관광객 많아? | 2025년 월별 외국인 관광객 소비 금액 추이를 보여줘 |
| 카페 어디가 좋아? | 관광객 카페 소비가 많은 읍면동 5곳을 주말·평일로 나눠 비교해줘 |
| 비 오면 어때? | 강수량이 10mm 이상인 날과 아닌 날의 입도객 수 평균을 비교해줘 |

- 지역(읍면동), 기간, 대상(도민/관광객), 비교 기준을 넣으면 더 정확합니다.
- 답변이 끝나면 "그럼 서귀포시는?", "업종별로 나눠줘"처럼 이어서 물어볼 수 있습니다.

## 5. 결과 확인과 재현 (검증 방법)
- 답변 아래 **실행한 SQL·코드 보기**를 펼치면 계산에 쓴 SQL과 파이썬 코드가 모두 나옵니다.
- 실행할 때마다 `runs/날짜-시각/` 폴더에 다음이 저장됩니다.
  - `report.html`: 질문, 답변, 표·차트, 재현용 SQL·코드 부록
  - `run.json`: 도구 호출 순서와 입력·출력 전체 기록
- 같은 데이터에 부록의 SQL을 DuckDB 등으로 실행하면 같은 수치를 다시 얻을 수 있습니다.
- AI의 문장 표현은 실행할 때마다 조금씩 달라질 수 있지만, 수치는 위 SQL·코드의 계산 결과에서만 나오도록 설계했습니다.

## 6. 터미널에서 사용 (선택)
```bash
python cli.py "애월읍 카페의 요일별 관광객 매출을 알려줘"
python cli.py                       # 대화 모드
python cli.py --no-samples          # 가상 샘플 제외
python cli.py --effort high "..."   # 더 꼼꼼한 분석
```

## 7. 자주 묻는 질문
- **"API 키가 올바르지 않습니다"**: 키 앞뒤 공백 없이 다시 붙여 넣으세요.
- **파일을 읽지 못했습니다**: 첫 줄이 컬럼 이름인 표 형태인지 확인하세요. 엑셀은 첫 번째 시트만 읽습니다.
- **답이 느려요**: 데이터가 크거나 질문이 넓으면 1~3분 걸릴 수 있습니다. 질문 범위를 좁히거나 `.env`의 `AGENT_EFFORT=low`로 바꾸면 빨라집니다.
- **샘플 데이터 경고가 나와요**: 왼쪽의 "데모용 가상 샘플 데이터 포함"을 끄고 실제 데이터를 넣으세요.
